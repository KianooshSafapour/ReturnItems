## چه شد

### 1) sms-center.tsx — «پیامک‌های خودکار سامانه»
- کارت قدیمی «هشدار پیامکی مرجوعی به مدیران» (SmsAlertsCard) **کامل حذف شد** — alert* از این پس legacy است.
- کارت جدید `SmsAutoMessagesCard` (id=`sms-auto`) با:
  - **Alert «لایه دوگانه»** — کلید سراسری اینجا + خاموش‌کردن هر مشتری در دفترچه مشتریان.
  - کارت a «ثبت مرجوعی ← اطلاع به مشتری»: سوییچ + قالب + چیپ + «بازگردانی پیش‌فرض».
  - کارت b «تأیید پرداخت ← اطلاع به مشتری»: فقط سوییچ (auto.paymentEnabled).
  - کارت c «تأیید مرجوعی ← اطلاع به آقای نوروزی (آماده پرداخت)»: سوییچ + قالب + بازگردانی.
  - کلید سراسری «درج فهرست اقلام مرجوعی در پیامک‌ها» (auto.includeItems).
  - ذخیره: `PUT /api/admin/sms-config` با بولی JSON — کلید `paymentSmsEnabled` = auto.paymentEnabled (قرارداد route).
- `AutoTemplateEditor` مشترک: textarea + چیپ (شامل `{{اقلام}}`/`{{تأییدکننده}}`) + شمارش پارت + پیش‌نمایش.
- **پیش‌نمایش = منطق بک‌اند** (sms-alerts.ts): با includeItems روشن و بدون جای‌نگهدار، «اقلام: …» به انتهای پیام افزوده می‌شود.
- پیش‌فرض‌های بازگردانی از `config.auto.defaults` (fallback به lib/sms).

## تأیید E2E (agent-browser — ورود kianoosh)
- بخش جدید رندر شد؛ قالب‌های پیش‌فرض کامل؛ includeItems روشن → «اقلام: شیر پرچرب ×۲، ماست ×۱» در انتهای پیش‌نمایش هر دو قالب.
- ذخیره → toast موفق + ردیف‌های `sms_customer_submit_*`/`sms_payment_enabled`/`sms_owner_notify_*`/`sms_include_items` در DB («۱»/«۰»)؛ خاموشی پرداخت → `sms_payment_enabled=0` ✓.
- چیپ {{اقلام}} اضافه‌شدنی ✓؛ بازگردانی پیش‌فرض ✓؛ ردیف‌های آزمایشی از DB پاک شدند.
- حساب من: «حرف نام‌خانوادگی» + تک‌حرف «ص» (صفاپور) + ۸ سواچ ✓؛ سازنده: مقنعه با چشم (۴ بیضی) ✓، کلاه هندسه جدید ✓.
- موبایل 390px بدون سرریز افقی؛ کنسول پاک؛ lint صفر خطا؛ tsc صفر خطا در ۴ فایل من.

## نکته برای عوامل بعدی
- PUT بولی‌ها را JSON boolean بفرستید (route خودش «۱»/«۰» می‌کند). کلید body برای پرداخت `paymentSmsEnabled` است نه `paymentEnabled`.
- legacy alert* در DB هنوز مقدار دارد (روشن با ۲ گیرنده از تست عامل دیگر) — UI آن حذف شده؛ ارسالش دیگر اجرا نمی‌شود. اگر پاک‌سازی می‌خواهید `sms_alert_*` را حذف کنید.
